# familyAlbum · 李旻泽家庭相册

基于开源 [Lightbox2](https://github.com/lokesh/lightbox2) 模板搭建的在线家庭相册。

## 内容

精选自网盘相册《ET231126010(李旻泽,李平,曾赟_初修片)》的 4 张初修片，均已压缩至 1200px 宽度以内。

## 在线预览

启用 GitHub Pages 后访问：`https://kh4tzjsjfy-eng.github.io/familyAlbum/`

## 本地预览

直接用浏览器打开 `index.html`，或：

```bash
python -m http.server 8000
# 访问 http://localhost:8000
```
